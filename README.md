# Gerenciamento de Funcionários

Exercício de revisão de Herança e Polimorfismo em Java, feito para
estudo antes de uma prova do curso técnico (CEFET-MG).

Uma classe base `Funcionario` e duas subclasses (`Gerente`, `Vendedor`)
que sobrescrevem `calcularSalario()` com regras diferentes (bônus fixo
e comissão). O array de funcionários é percorrido tratando todos os
objetos como `Funcionario`, sem verificar o tipo exato de cada um.
